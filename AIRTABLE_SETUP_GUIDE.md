## Step-by-Step Table Creation

### IMPORTANT: Create Separate Tables
Each entity (Businesses, Leads, etc.) must be a **separate table**, not fields in one table.

---

## Table 1: Businesses (Create First)

**Why first:** Other tables link to this one.

### Steps:
1. In Airtable, click **"+ Add a table"** or rename "Table 1" to "Businesses"
2. Create these fields in order:

| Field Name | Field Type | Required | Notes |
|------------|------------|----------|-------|
| Name | Single line text | ✅ Yes | - |
| Timezone | Single line text | ✅ Yes | IANA format (e.g., "America/New_York") |
| Phone | Phone number | ❌ No | - |
| Email | Email | ❌ No | - |
| Active | Checkbox | ❌ No | - |

**Note:** "Created" field is auto-generated by Airtable - don't create it manually.

### Field Type Mapping:
- **Single line text** = "Single line text" in Airtable UI
- **Phone number** = "Phone number" in Airtable UI
- **Email** = "Email" in Airtable UI
- **Checkbox** = "Checkbox" in Airtable UI

## Common Mistakes to Avoid

❌ **Creating fields in one table instead of separate tables**
- Each entity (Businesses, Leads, etc.) must be a **separate table**

❌ **Wrong field types**
- "Single line text" not "Text"
- "Date with time" not just "Date" (for Start UTC/End UTC)
- "Long text" not "Single line text" (for Transcript, Notes, etc.)

❌ **Missing required fields**
- Timezone in Businesses (required)
- Transcript in Interactions (required)
- Start UTC and End UTC in Appointments (both required)

❌ **Wrong select option names**
- Must match exactly: "New" not "new", "CONFIRMED" not "Confirmed"

❌ **Creating "Created" field manually**
- This is auto-generated by Airtable - don't create it
